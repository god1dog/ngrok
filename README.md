# ngrok-lite (Go)

Минимальный аналог ngrok на Go:

- **server** запускается на VDS и принимает публичные HTTP-запросы;
- **client** подключается к серверу и проксирует трафик в ваш локальный сервис;
- у клиента есть маленькая веб-страница (dashboard) как у ngrok на `http://localhost:4040`.

## Быстрый старт

### 1) Запустите сервер на VDS

```bash
go run ./cmd/server -addr :8080 -public-base http://YOUR_VDS_IP:8080
```

### 2) Запустите локальный сервис

Например:

```bash
python3 -m http.server 3000
```

### 3) Запустите клиента на вашей машине

```bash
go run ./cmd/client -server http://YOUR_VDS_IP:8080 -local http://localhost:3000
```

Клиент выведет публичный URL вида:

```text
http://YOUR_VDS_IP:8080/t/<client_id>
```

Все запросы на этот URL будут проброшены в `-local`.

## Dashboard клиента

Откройте:

- `http://localhost:4040`

На странице видно:

- публичный URL туннеля;
- куда идет форвардинг;
- последние запросы (метод, path, статус, время).

## Флаги

### server

- `-addr` — адрес прослушивания (по умолчанию `:8080`)
- `-public-base` — базовый публичный URL для выдачи tunnel URL

### client

- `-server` — адрес сервера (по умолчанию `http://localhost:8080`)
- `-local` — локальный upstream (по умолчанию `http://localhost:3000`)
- `-id` — фиксированный id туннеля (опционально)
- `-dashboard` — адрес dashboard (по умолчанию `:4040`)

## Ограничения демо-версии

- только HTTP/HTTPS трафик;
- long-poll модель (клиент постоянно опрашивает сервер);
- body ограничен ~4 MB на запрос/ответ;
- нет авторизации/шифрования/ACL;
- не production-ready без доработок.
